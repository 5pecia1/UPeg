# Changelog

UPeg has not had a versioned release yet. This repository receives
verified exports from the development repository as ordinary pull
requests — see the git history and README's *Project status* section.

Notable user-facing changes and breaking changes will be recorded here
once versioned releases begin. Until then, breaking changes are called
out in the README where they apply — for example the
[File wire format](https://github.com/5pecia1/UPeg/blob/main/README.md#file-input-wire)
migration note.
