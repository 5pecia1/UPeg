One Tool, seven surfaces

A Tool is declared once — a Rust #[upeg::tool] macro, a TOML toolkit entry, a WASM plugin, or an imported MCP server — and the same inputs, outputs, and result envelope travel to every surface that can run it:

  • CLIscriptable calls and shell completions
  • TUIkeyboard-driven board in the terminal
  • Desktopnative window with embed support
  • PWAinstallable browser build, self-hosted
  • Chrome extin-page detectors and dispatch
  • MCPserve a prepared board to AI agents
  • HTTPlocal REST and MCP-over-HTTP API

How it works

  1. Wrap or write a Tool. Point a TOML toolkit at an existing command or HTTP endpoint — no code — or scaffold a WASM plugin / Rust tool for typed logic.
  2. Pin it to a board. Boards group the tools, input presets, and written guidance for a task — personal boards in your home directory, project boards in a repo's upeg.toml.
  3. Call it from anywhere. Run it from the CLI or TUI, tap it on the desktop or PWA, drive it from the browser extension, or let an AI agent call it over MCP — the result contract is identical.

Honest boundaries

Seven surfaces does not mean universal parity. UPeg renders unsupported states honestly instead of pretending:

  • PWA and Chrome extension are sandboxed. Tools that need the native loader runtime run through a paired local host, or show an honest unsupported state.
  • Controlled Embed selectors can break. When a SaaS changes its UI, the mapping fails at call time and is re-mapped by hand — there is no automatic selector tracking.
  • Some invokers need a network or a session. Invoker::Llm needs an LLM API; hotkey triggers need a graphical session. Missing dependencies surface as diagnostics, not silent failures.
  • Local-first means the cloud is optional. Credentials live in environment variables or the OS keychain, execution logs record metadata only, and the network interface starts on loopback with bearer auth.
  • Not a replacement for specialized apps. UPeg wraps and orchestrates tools; it is not an IDE, password vault, automation platform, or mobile-first product.
