Privacy

This site. No analytics, no tracking pixels, no remote font or script requests — every asset is served from this site. Fonts come from your system.

The product. UPeg is local-first: boards, presets, and execution history live on your machine. Credentials are stored by name in TOML and resolved through the OS keychain — plaintext values are never written to manifests, state, logs, or network responses. The execution log records metadata only (time, tool id, surface, status, duration). Network listeners are explicit-start and loopback-first, and every HTTP route except /healthz requires a bearer token.

Details: security absolutes.

FAQ

Is there a download or installer?

Not yet — UPeg is pre-release and built from source (cargo build --release -p upeg-cli --bin upeg). Packaged desktop downloads are planned once releases start. See the installation guide.

Does UPeg send my data anywhere?

No. Everything runs locally by default; there is no telemetry. Optional cloud sync is designed to be end-to-end encrypted, and credential values never leave the OS keychain.

How do AI agents use my tools?

upeg mcp exposes a prepared board over MCP (stdio or HTTP). The agent sees only the tools and guidance you pinned — connecting a board does not execute anything by itself. See board and agent workflow.

Do all seven surfaces support every tool?

No — and UPeg says so. Sandboxed surfaces (PWA, Chrome extension) either pair with a local host or show an honest unsupported state. See honest boundaries above and the surface contract.

Is UPeg free and open source?

Yes — Apache-2.0, developed in the open at github.com/5pecia1/UPeg. A Korean version of the README is linked from the repository; the docs themselves are English-only.
