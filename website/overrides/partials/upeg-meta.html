Privacy

This site. No analytics, no tracking pixels, no remote font or script requests — every asset is served from this site. Fonts come from your system.

The product. UPeg is local-first: boards, presets, and execution history live on your machine. Credential references are stored by name in TOML; values resolve from environment variables or the OS keychain at execution time. Plaintext values are never written to manifests, state, logs, or network responses. The execution log records metadata only (time, tool id, surface, status, duration). Network listeners are explicit-start and loopback-first, and every HTTP route except /healthz requires a bearer token.

Details: security absolutes.

FAQ

Is there a download or installer?

Not yet — UPeg is pre-release and built from source (cargo build --release -p upeg-cli --bin upeg). Packaged desktop downloads are planned once releases start. See the installation guide.

Does UPeg send my data anywhere?

By default, UPeg processes and stores data locally. Tools you choose to run can send inputs and required credentials to external services, including HTTP, LLM, and remote MCP tools. Credential values resolve from environment variables or the OS keychain at execution time. Cloud sync is not available yet.

How do AI agents use my tools?

upeg mcp exposes all tools available on its MCP surface to an agent over stdio; upeg mcp --board dev limits it to that board's pins and guidance. The HTTP host separately serves MCP at /mcp. Connecting does not run the board's tools. See board and agent workflow.

Do all seven surfaces support every tool?

No — and UPeg says so. Sandboxed surfaces (PWA, Chrome extension) either pair with a local host or show an honest unsupported state. See honest boundaries above and the surface contract.

Is UPeg free and open source?

Yes — UPeg's own code is Apache-2.0 at github.com/5pecia1/UPeg. Development happens in a private source repository; verified exports are published here, and maintainers import accepted public contributions. A Korean version of the README is linked from the repository; the docs themselves are English-only.
