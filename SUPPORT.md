# Support

upeg is an early-stage project maintained on a best-effort basis — there
is no support SLA.

## Where to ask

- **Bugs** — open an issue using the *Bug report* template.
- **Feature requests** — open an issue using the *Feature request*
  template.
- **How-to questions** — check the
  [documentation](https://github.com/5pecia1/UPeg/blob/main/docs/index.md)
  first (the
  [quick start](https://github.com/5pecia1/UPeg/blob/main/docs/guides/quick-start.md)
  and
  [troubleshooting](https://github.com/5pecia1/UPeg/blob/main/docs/guides/troubleshooting.md)
  guides cover most setup problems), then open an issue.
- **Security** — never in issues; follow
  [SECURITY.md](https://github.com/5pecia1/UPeg/blob/main/SECURITY.md).

When reporting a problem, `upeg doctor --json` output and the exact
command or UI steps help most. Never paste tokens, credential values, or
`~/.upeg/server.json` contents into an issue.

## Response expectations

Replies are best-effort. For security reports we aim for an initial
response within 7 business days (see SECURITY.md); other issues have no
committed timeline.
